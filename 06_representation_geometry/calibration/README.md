# Geometry calibration supplement

Companion to the v1.0.1 replication package, manuscript Section 6.1. This archive contains the retained failed first calibration (P7-G0-V001) and corrected calibration (P7-G0-V002), their configurations, synthetic diagnostic rows, quality reports, environment records and canonical source modules. No securities or licensed observations occur in these synthetic cases.

The main public exhibit replay does not require these files. Extract this archive separately to inspect the six diagnostic gates. The canonical source reflects the corrected implementation; the failed first-run outputs are preserved as historical evidence rather than a promise that the corrected code reproduces the old defect. Re-running calibration is an evidence-producing simulation and remains subject to the authors' global resource-controller policy on their Mac/campus nodes. No calibration was rerun for this publication.

Interpretation: the hidden-layer widths are 128, 64 and 32. Declining absolute participation ranks across these layers do not by themselves establish increasing concentration relative to width or distinguish learned compression from architectural constraints. The manuscript's geometry comparisons are descriptive; the functional pricing test is separate.
